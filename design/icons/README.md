# Icons

سبع عشرة أيقونة خطّية على شبكة 24، بسُمك 2px، بأطراف مقصوصة (square) وزوايا حادّة (miter)، على روح الكوفي: زوايا 45° وعقد بدل الدوائر. مرسومة بـ `currentColor`، فتأخذ لون النص حين تُضمَّن SVG، وتصلح قناعًا CSS أيضًا.

- التنقّل: `home` (باب بعقد)، `menu`، `close`، `search` (عدسة معيّنة)، `next` (تشير يسارًا، اتجاه القراءة)، `prev`.
- الوسائط: `play` و`pause` (لا تُعكسان في RTL).
- المحتوى: `book`، `calendar`، `location`، `user`، `favorite` (نجمة ثمانية)، `share`، `download`، `check`، `plus`.
- الحجم الأدنى 20px؛ لا تملأها ولا تغيّر سُمكها.
